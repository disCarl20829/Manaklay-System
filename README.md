# Manaklay-System
A full-on accounting, cashier, and inventory system for a beach resort.


TO INITIALIZE PROJECCT:
1. INSTALL NODE.JS
2. OPEN CMD/TERMINAL
3. PASTE AND ENTER CODE:
   
mkdir manaklay-api

cd manaklay-api

npm init -y  

npm install express mysql2 cors dotenv


TO TEST USE ``THUNDER CLIENT`` ON VSCODE

SAMPLE LINK: ``http://localhost:3000/api/product-categories``
